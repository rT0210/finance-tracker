# Finance Tracker

Приложение для учёта доходов и расходов.  
React + TypeScript + Redux Toolkit + Tailwind CSS.

## Функционал

- Добавление, редактирование, удаление транзакций.
- Фильтрация: все / доходы / расходы.
- Поиск по описанию.
- Данные хранятся в Redux (localStorage пока нет, но можно добавить).

## Технологии

- React (хуки, компоненты)
- TypeScript
- Redux Toolkit
- Tailwind CSS
- Vite

## Как запустить

```bash
git clone https://github.com/rT0210/finance-tracker.git
cd finance-tracker
npm install
npm run dev
